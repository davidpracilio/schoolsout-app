# Agent Instructions

## General Guidelines

### Do Not Auto-Launch the Site
- **Do not** open URLs or launch the development server automatically after making changes
- Users will manually start the dev server and refresh the browser as needed
- Only launch the site if explicitly requested by the user

### When Completing Tasks
- Use `attempt_completion` without the `command` parameter to avoid launching the site
- Provide a clear summary of changes made
- Let the user decide when to test the changes

### Development Workflow
- Make code changes as requested
- Update files and components
- Provide clear feedback on what was changed
- Wait for user feedback before making additional changes
